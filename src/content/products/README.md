# products

Empty on purpose.

`products` are evergreen items sold through an **external store** (Bonfire,
Fourthwall, etc.), so every entry needs a `buyUrl`. The team hasn't picked a
store yet and doesn't want to commit to one, so there's nothing here.

Astro logs *"The collection products does not exist or is empty"* while this is
empty. Expected.

Batch jersey drops don't belong here — they live in `preorders`, which takes
orders on-site with no third-party account. See `docs/PREORDERS.md`.
