# results

Empty on purpose. The fabricated stat lines that were here during build-out
were removed — inventing tournament results puts false claims on a real site.

Astro logs *"The collection results does not exist or is empty"* on every build
while this is empty. That warning is expected and goes away with the first real
entry.

Add results through Pages CMS after an event (see `docs/EDITING.md`). Until
then `/stats` renders its empty state, and the homepage shows no stats at all.
